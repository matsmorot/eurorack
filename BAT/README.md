# BAT
BAT is a PT2399 based, clock synced delay by Hagiwo. I just made my own panel and PCB versions.

  <li>Wrong footpint for R9. Just a bit long, so still works.</li>
  <li>R28 should probably be higher than 330R.</li>
  <li>U2 and U3 have different footprints for some reason.</li>
